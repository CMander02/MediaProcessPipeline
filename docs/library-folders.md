# 文件夹与浏览模式

更新代码并构建前端后，重新打开 MPP 桌面应用。命令行启动的服务需要重启 daemon。后端仍使用端口 18000。

## 整理文件

- 标题栏右侧可以新建文件夹，并切换网格或浏览视图。
- 标题栏的「全部 / 文件夹」决定范围。「文件夹」显示文件夹和未归类内容；「全部」把所有内容按当前排序排在一起，不分文件夹，卡片上标出所在文件夹。手机上这个切换在搜索框左边。下次打开 MPP 时沿用上次选的范围。
- 网格首页显示文件夹和未归类内容。进入文件夹后保留网格视图。在文件夹里再点「文件夹」回到总览。
- 默认按最近处理时间混合排序，文件夹没有固定优先级。文件夹取其中内容的最近处理时间；空文件夹放在末尾。重命名和移动不会刷新处理时间。
- 浏览视图左侧显示文件夹树。展开、折叠文件夹不改变当前视频。
- 切换内容后，旧播放器停止。再次打开内容时恢复播放位置和结果标签。
- 前进、后退恢复访问位置。有未保存的编辑时，可以继续编辑或放弃并切换。
- 切换网格 / 浏览、切换全部 / 文件夹不算一次访问，后退不会在两种视图之间来回。在网格的文件夹里后退，回到文件夹总览。
- 文件夹只有一层。每项内容最多属于一个文件夹。
- 文件夹是分类关系。归档的实际磁盘路径不会因分类变化而改变。
- 删除文件夹后，内容回到未归类。处理记录和文件会保留。

## 文件夹封面

- 封面默认用文件夹里最近处理的内容的封面，新内容进来后封面随之更新。封面后面叠着两层，与单个视频区分。右下角是内容数。
- 在文件夹里，内容菜单中的「设为文件夹封面」固定封面；文件夹菜单中的「恢复自动封面」取消固定。固定的内容移出文件夹后，封面自动恢复。
- B 站合集建的文件夹在封面左下角显示 UP 主头像，信息行标「合集」。头像在文件夹第一次显示时从 B 站读取，缩小后存进资料库数据库，之后不再访问 B 站。读取失败 6 小时内不再重试。
- 文件夹菜单中的「批量处理」提供与批量操作相同的动作。

## 批量操作

勾选文件后，点“移到文件夹…”选择目标位置。在文件夹内可以直接点“移到未分类”。单个文件的菜单也提供这两个入口。

在网格中可以将文件拖到文件夹卡片上。拖动一个已选文件时，会一起移动全部已选文件。在文件夹内或「全部」里拖动时，页面会显示文件夹和“未分类”目标。

浏览模式支持拖到左侧文件夹上。拖动期间，左栏底部会显示“未分类”目标。移动当前视频时保留播放器、播放位置和结果标签。

勾选内容后，可翻页继续选择。全选本页会追加本页内容。切换文件夹或筛选条件会清空选择。

“批量操作”支持继续、重试、从断点继续、全部重新处理、移动、移出、导出、媒体保留和删除。文件夹卡片也提供整夹操作。

执行前，服务端确定范围，并显示内容数、处理记录数和跳过项。执行后显示成功项和失败项。成功项从所选集合中移除，失败项可以再次预览。

删除内容会删除它的全部历史处理记录和生成文件。处理中任务先停止。若文件删除失败，删除清单会保留，重启或再次预览后可以继续删除。新增处理记录或文件夹归属改变时，需要重新确认删除范围。

## B 站合集

导入时勾选“以合集创建文件夹”。文件夹按合集标识绑定，重复导入会复用该文件夹。手动改名不会改变绑定。

新视频导入时，服务端先检查已记录的合集成员。必要时查询 B 站合集信息，并归入已有合集文件夹。分 P 内容保留各自的内容标识。

- 同时指定普通文件夹并勾选合集文件夹时，所选合集成员进入合集文件夹。
- 内容已有手动归属，或曾被手动移出文件夹时，默认保留该选择。
- 勾选“移动已有归属的内容”后，导入可以改变已有归属。
- 命中多个已有合集时，保留原归属，并提示手动处理。
- 合集查询失败时，导入结果会显示分类错误。已成功提交的处理任务会保留。

## 持久化与离线

分类关系和合集绑定存入资料库数据库。目录使用独立 revision。分类变化不会重新下载媒体。

客户端按服务器和资料库保存目录快照。原生客户端用归档 ID 对照内容标识和文件夹归属。离线时显示最后成功取得的目录；新增和修改分类需要连接服务器。
